🚀 UTILISATION RAPIDE
=============================================================================

OPTION 1 - Test rapide (recommandé pour commencer)
---------------------------------------------------
Ajoutez temporairement dans n'importe quelle page:

import BarcodeScannerQuickTest from '../components/ui/BarcodeScannerQuickTest.jsx';

<BarcodeScannerQuickTest />

→ Cliquez sur le bouton flottant en bas à droite


OPTION 2 - Modal dans une page existante
-----------------------------------------
import { useState } from 'react';
import BarcodeScannerModal from '../components/ui/BarcodeScannerModal.jsx';

const [showScanner, setShowScanner] = useState(false);

<BarcodeScannerModal
  isOpen={showScanner}
  onClose={() => setShowScanner(false)}
  onConfirm={(code, format) => console.log(code, format)}
  autoConfirm={true}
/>


OPTION 3 - Page complète dédiée
--------------------------------
Ajoutez dans routes.jsx:

import { ProductScannerPage } from '../features/inventory';

{
  path: '/inventory/scanner',
  element: <ProductScannerPage />,
}


OPTION 4 - Via ProductDetailPage
---------------------------------
→ Le bouton "Scanner" a déjà été ajouté !
→ Allez sur n'importe quelle page de détail produit
→ Cliquez sur "Scanner"
